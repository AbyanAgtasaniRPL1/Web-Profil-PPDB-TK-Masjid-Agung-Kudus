# 🏫 Website Profile & PPDB TK Masjid Agung Kudus

Platform berbasis web yang dirancang untuk menyajikan profil sekolah serta sistem Penerimaan Peserta Didik Baru (PPDB) secara online untuk TK Masjid Agung Kudus. Sistem ini mempermudah calon orang tua murid untuk mengakses informasi sarana, prasarana, kegiatan, hingga melakukan pendaftaran siswa baru secara praktis.

---

## 📌 Fitur Utama

- 🌐 **Profil Sekolah & Informasi:** Menampilkan profil lengkap sekolah, visi-misi, sarana/prasarana, daftar tenaga pendidik, serta ekstrakurikuler.
- 📝 **Pendaftaran PPDB Online:** Formulir pendaftaran siswa baru secara online untuk memudahkan calon wali murid tanpa harus datang langsung ke lokasi.
- 🖼️ **Galeri Kegiatan:** Dokumentasi foto kegiatan siswa-siswi dan guru di lingkungan sekolah.
- 💬 **Kontak & Pesan:** Layanan kontak saran/pesan langsung dari pengunjung kepada pihak sekolah[cite: 1].
- ⚙️ **Panel Admin (CRUD Database):** Pengelolaan data pendaftar, pesan masuk, serta unggah/hapus foto galeri[cite: 1].
